# StudentHelper HR

StudentHelper HR je prototip web aplikacije za studente i maturante u Hrvatskoj. Cilj aplikacije je prikazati studentske informacije na jednom mjestu, poput stipendija, studentskih poslova, smještaja, prehrane, događanja i rekreacije.

## Opis

Projekt prikazuje osnovni kostur aplikacije i glavnu korisničku interakciju. Korisnik može otvoriti početnu stranicu, pregledati kategorije, odabrati studentske poslove, koristiti osnovni filter, pregledati rezultate i otvoriti izvor oglasa.

## Funkcionalnosti

- početna stranica
- pregled kategorija
- stranica studentskih poslova
- osnovni filter grada i područja posla
- prikaz testnih rezultata
- detalji oglasa
- link na vanjski izvor
- stranica O nama

## Tehnologije

- HTML
- CSS
- Git
- GitHub

## Napomena

Aplikacija je izrađena kao prototip za projektni zadatak. Filteri i rezultati služe za demonstraciju interakcije, a ne za stvarno dohvaćanje podataka iz baze.
